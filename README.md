# 📊 Sales / Order Dashboard (Power BI)

## 🔍 Overview
This project focuses on analyzing sales and order data to evaluate business performance and generate actionable insights using Power BI. The dashboard provides a comprehensive view of revenue trends, customer behavior, and regional performance.

## ⚙️ Tools & Technologies
- Power BI
- Microsoft Excel

## 📈 Key Features
- Developed an interactive dashboard to monitor revenue and order performance  
- Analyzed customer trends and purchasing behavior  
- Identified top-performing products, categories, and regions  
- Implemented slicers and filters for dynamic and user-friendly analysis  

## 📊 Key Insights
- Identified high-performing regions contributing to maximum revenue  
- Analyzed sales trends over time to understand business growth patterns  
- Highlighted top products driving sales performance  
- Provided data-driven insights to support business decision-making
